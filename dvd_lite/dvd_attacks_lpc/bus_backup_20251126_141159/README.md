# bus

`bus` 디렉터리는 테스트베드 내 여러 서비스와 모듈이 기록하는 로그 파일을 저장합니다. 로그는 CTI 에이전트가 공격을 탐지하고 MTD가 방어 전략을 선택하는 데 사용되는 주요 데이터 소스입니다.

## 주요 로그 파일

| 파일명 | 설명 |
| --- | --- |
| **`bus_network.log`** | 네트워크 패킷 정보(패킷 길이, 출발/도착 포트 등)를 기록합니다. 공격 탐지 모델에서 네트워크 기반 피처를 추출할 때 사용합니다. |
| **`bus_telemetry.log`** | 드론의 고도, 속도, 배터리 전압, 자세(pitch/roll) 등 텔레메트리 데이터를 기록합니다. GPS 스푸핑 및 센서 변조 공격을 탐지하는 데 활용됩니다. |
| **`bus_qos.log`** | CPU 사용률, 패킷 손실률, 평균 지연시간 등 시스템 QoS(품질) 지표를 기록합니다. MTD 적용 시 성능 저하 여부를 감지하는 데 사용됩니다. |
| **`bus_container_telemetry.log`** | 컨테이너 상태(메모리/CPU 사용률 등)를 모니터링합니다. |
| **`bus_system_events.log`** | 시스템 수준 이벤트(로그인, 서비스 재시작 등)를 기록합니다. |
| **`bus.log`** | 메타데이터 및 종합 로그를 저장할 수 있으나, 일부 에이전트는 사용하지 않습니다. |

각 로그는 JSON 라인 형식으로 저장되며, CTI 에이전트는 `RealTimeLogReader` 클래스를 통해 실시간으로 읽어 큐에 넣습니다. 로그 포맷을 변경할 경우 CTI 에이전트의 전처리 코드(`preprocess_log_to_features`)도 함께 수정해야 합니다.
